# Livepeer brand assets

Official files from https://livepeer.org/brand (downloaded 25 Sep 2026), used unmodified for "Powered by Livepeer" attribution.

- `livepeer-lockup-black.svg`, `livepeer-lockup-white.svg`: symbol + wordmark
- `livepeer-symbol-black.svg`, `livepeer-symbol-white.svg`: symbol only

Livepeer's usage notes: white on dark, black on light; never rotate, stretch, recolor, or apply effects; clear space equal to the symbol width on all sides; minimum size 16px for the symbol, 24px tall for the lockup.
